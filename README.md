# Monitoria-Introdução-à-Computação

## Repositório criado para o auxílio dos alunos referente a disciplina Introdução à computação referente ao semestre do período 2026/2  

Aqui vamos estar resolvendo e deixando salvo os nossos exercícios. Utilizarei o arquivo Códigos.c para guardar todos os códigos resolvidos.  
Na aba Code do repositório vocês podem clicar em Branch e criar uma nova Branch com o nome de vocês, onde vocês vao salvar o código de vocês (acredito que estejam programando pelo vscode) e realizar o commit na branch que irá salvar todas as modificações que vocês realizaram nos arquivos no vscode e assim consiguirei visualizar o código de vocês, farei a junção com o arquivo Código.c mantendo todos os códigos para rápida visualização de lá.  
Qualquer dúvida referente ao site e vscode podem mandar mensagem no Github em discussões ou no teams.
